# DeepSeek 双机（.14 + .12）V1 与 V2 完整实测数据总表

- **测试集**：`v14配套testset`（48 条真实多轮 Agent 会话，上下文 `7K～264K` tokens）
- **指标口径说明**：
  - **有效吐字(不含工具) 全轮 / 热续轮**：`输出 token 总数 ÷ 模型侧总耗时`（含排队 + Prefill + 思考 + 解码，严格扣除工具执行耗时）；**全轮**包含首轮冷启动，**热续轮**为进入多轮后的稳态表现。
  - **纯解码 P50**：去掉首字等待后的纯打字机出字速度中位数。
  - **续轮等待·思考首字 / 可见正文**：扣除工具时间后，等到模型吐出第一个思考字（`reasoning`）与真正可见正文/工具调用字的平均耗时。
  - **停顿违例 `C1 / C2`**：`C1` 为单轮首字等待超过 120 秒的笔数；`C2` 为单轮流式吐字中途卡顿超过 2 秒的笔数。
  - **双机路由 `.14/.12` (粘性/新分配/溢流)**：两台机器实际承接笔数，括号内依次为会话粘性命中数、新会话直分数、溢流到无粘性 `sglang-router` 的笔数。
